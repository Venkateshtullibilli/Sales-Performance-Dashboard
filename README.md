# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview

This project focuses on analyzing sales data and developing an interactive Sales Performance Dashboard using Microsoft Excel.

The objective is to transform raw sales data into meaningful business insights, monitor sales performance, identify top-performing products and evaluate salesperson performance to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products.
- Evaluate individual salesperson performance.
- Analyze sales trends over different time periods.
- Understand sales performance across different locations.
- Present key business insights through an Excel dashboard.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization

## 📂 Workbook Structure

| Worksheet | Description |
|---|---|
| Master Data | Contains the raw sales dataset. |
| Dashboards | Presents sales performance visually. |
| Products | Supports product-wise sales analysis. |
| Sales Mans | Supports salesperson performance analysis. |
| Pivot Tables | Contains summarized sales data for analysis. |

- Product-wise Sales Performance

- Monthly Sales Trends
